# Northwind Power BI Capstone Project

This project analyzes Northwind Traders sales data using Excel and Power BI.

## Tools Used
- Power BI
- Microsoft Excel

## Project Files
- Power BI Dashboard (.pbix)
- Excel EDA Analysis
- Project Presentation
- Documentation

## Key Insights
- Customer segmentation analysis
- Sales performance by region
- Product category revenue trends
- Supplier distribution analysis

The interactive Power BI dashboard is included as a .pbix file in this repository.
To view the dashboard:
1. Download the .pbix file
2. Open it using Power BI Desktop
